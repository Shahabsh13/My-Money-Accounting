# حذف کامل ویجت «نمودار روند روزانه»

## خواسته

کاربر با اسکرین‌شات کارت «نمودار روند روزانه» در صفحهٔ خانه نوشت: **«این ویجت رو کلا پاک کن»**.

## چرا با یک پرچم پنهان‌سازی حل نشد

قبلاً اسکریپت کوچکی (`008-hesabno-hide-daily-trend-widget.js`) در بوت، مقدار
`chartTrend: false` را داخل `hesabno:homeWidgets` می‌نوشت. اما آن اسکریپت **فقط یک‌بار** کار
می‌کرد (`if key exists → return`)؛ پس هر دستگاهی که از قبل این کلید را داشت — یا هر کاربری که
بعداً چیدمان ویجت‌ها را ذخیره می‌کرد — دوباره نمودار را می‌دید. ضمناً ویجت همچنان در فهرست
«مدیریت ویجت‌ها» قابل روشن‌کردن بود.

## چه چیزی حذف شد

| محل | تغییر |
| --- | --- |
| `067-inline.js` — کامپوننت `y9` | کل بدنهٔ نمودار روند روزانه (نقاط تعاملی، نوارهای ساعتی، کارت جزئیات) حذف شد (~۷ کیلوبایت) |
| `067-inline.js` — سوییچ ویجت‌ها | شاخهٔ `case "chartTrend"` حذف شد |
| `067-inline.js` — `cl` (ترتیب ویجت‌ها) و `dl` (پیش‌فرض‌ها) | کلید `chartTrend` حذف شد |
| `067-inline.js` — `iN` (فهرست مدیریت ویجت‌ها) | ردیف «نمودار روند روزانه درآمد و هزینه» حذف شد |
| `008-hesabno-hide-daily-trend-widget.js` | فایل حذف شد؛ برچسب `<script>` از `index.html` و ردیفش از `src/MANIFEST.txt` برداشته شد |
| `235-...css` | هر ۸ قاعدهٔ `.hesabno-trend-detail` (کارت جزئیات زیر نمودار) حذف شد |

## سازگاری با دادهٔ ذخیره‌شدهٔ کاربران

دستگاه کاربرانی که ویجت را روشن داشته‌اند هنوز `chartTrend` را در `hesabno:homeWidgets` (و در
آرایهٔ `order`) دارد. هنگام خواندن تنظیمات این مقدار **بی‌صدا کنار گذاشته می‌شود**:

```js
const Ae = { ...dl, ...JSON.parse(ge) };
delete Ae.chartTrend;
if (Array.isArray(Ae.order)) Ae.order = Ae.order.filter(Pe => Pe !== "chartTrend");
```

به این ترتیب جای خالی/کارت ناشناس در داشبورد ساخته نمی‌شود و نیازی به مهاجرت نوشتنی (و یک نوشتن
اضافه در بوت) نیست.

## چیزهایی که دست‌نخورده ماندند

- انتخابگر بازهٔ «امروز (ساعتی) / ۷ روزه / ۱۴ روزه / یک ماهه» (`gg`) و قلاب دادهٔ `bg` چون
  نمودارهای **میله‌ای سرفصل‌ها** و **دوناتی** از همان‌ها استفاده می‌کنند.
- سایر ویجت‌های خانه و مجموعهٔ «مدیریت ویجت‌ها».

## بازبینی با jsdom

با ذخیرهٔ قدیمی `{"chartTrend":true,"order":["chartTrend","chartCategoryBars","chartDonut"]}`:
داشبورد بدون خطا بالا می‌آید، عنوان «نمودار روند روزانه» و `.hesabno-trend-detail` وجود ندارند،
و نمودار میله‌ای و دوناتی همچنان رندر می‌شوند.
