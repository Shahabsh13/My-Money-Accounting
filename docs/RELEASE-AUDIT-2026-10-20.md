# گزارش بازبینی پیش از ساخت — ۲۰ اکتبر ۲۰۲۶

## مبنا و حدود بررسی

- مبنا: `107e152`، نسخهٔ ادغام‌شدهٔ PR شمارهٔ ۱۲ روی main.
- شاخهٔ اصلاحات: `arena/cea4abab-my-money-accounting`.
- ۲۷۸ تست موجود، پیش از تغییرات همگی موفق بودند. بنابراین سبز بودن تست‌های اولیه به‌معنی نبود باگ نبود.
- بررسی شامل خواندن دستی مسیرهای حساس ذخیره/بازیابی، پیوست، SMS، اعلان و پل اندروید، بازتولید ایرادها با توابع واقعی، کنترل نحوی همهٔ فایل‌های JS/CJS و بررسی منابع و تنظیمات ساخت بود.
- این گزارش ادعای بررسی معنایی تک‌تک خطوط همهٔ کتابخانه‌های ثالث، ممیزی امنیتی رسمی یا اثبات نبود هرگونه باگ ندارد.

## پیش از ساخت و نصب

- **APK/AAB ساخته نشده است.** محیط این بررسی Java/Android SDK آمادهٔ کامپایل ندارد؛ مطابق خواستهٔ قبلی ساخت کنار گذاشته شد. بررسی نحوی Java و تست‌های ساختاری جای assembleDebug، Android Lint و آزمایش دستگاه را نمی‌گیرند.
- برای اولین بررسی عملی، یک debug build از **شاخهٔ اصلاح‌شده** بگیرید؛ تا پیش از ادغام اصلاحات، main شامل این اصلاحات نیست.
- پیش از به‌روزرسانی اپ دارای دادهٔ واقعی، بکاپ معمولی بگیرید و بازیابی آن را در نصب آزمایشی جداگانه تأیید کنید. شمارهٔ نسخه و کلید امضا در این بازبینی عوض نشده‌اند؛ برای انتشار بعدی versionCode باید از نسخهٔ منتشرشده بیشتر شود.

### چک‌لیست دستگاه واقعی

1. نصب و شروع سرد؛ بستن/بازکردن؛ برگشت سخت‌افزاری؛ کارکرد بدون اینترنت.
2. ثبت و ویرایش درآمد/هزینه، چک و قسط؛ تأیید مانده و گزارش؛ حفظ اطلاعات بعد از restart.
3. پشتیبان/بازیابی با تصاویر واقعی و فایل حجیم؛ مقایسهٔ تعداد و مبالغ و خود تصاویر پس از بازیابی.
4. رد و قبول مجوز SMS؛ رسیدن پیام جدید بلافاصله پس از مجوز؛ تست با پیام واقعی و فرستندهٔ واقعی بانک.
5. اعلان چک/قسط/پیامک؛ لمس از پنل و از اعلان اندروید؛ شروع سرد با لمس اعلان؛ مقصد حذف‌شده؛ خواندن همه؛ ماندگاری وضعیت پس از restart.
6. یادآور پس از reboot و هنگام بسته‌بودن برنامه؛ رفتار بهینه‌سازی باتری سازندهٔ گوشی.
7. گرفتن عکس فیش/چک، گالری، ذخیره در دانلودها، SAF/درایو و ردکردن مجوزهای مربوطه. مجوز و قابلیت دوربین عمداً حذف نشده است.
8. نصب آپدیت روی نسخهٔ امضاشدهٔ قبلی، بدون حذف اپ؛ تأیید حفظ داده‌ها.

## محدودیت‌ها و ریسک‌های باقی‌مانده

- عدم مشاهدهٔ شکست در بررسی فعلی، تضمین «کاملاً بدون باگ» نیست؛ همهٔ مسیرهای UI روی گوشی و تمام ترکیب‌های داده اجرا نشده‌اند.
- نمونه‌های بانکی ۴۰ قالب تست عمومی‌اند؛ پوشش همهٔ قالب‌های ۱۷ بانک یا اصالت همهٔ نام‌های فرستنده مستقلاً تأیید نشده است. در موارد مبهم یا قالب پشتیبانی‌نشده، بررسی دستی کاربر لازم است.
- تاریخچهٔ اعلان‌ها و پیوست‌ها ممکن است در استفادهٔ طولانی رشد کند؛ سیاست حذف اعلان خوانده‌نشده عمداً تغییر نکرد تا خلاف درخواست کاربر نباشد. خطای پرشدن حافظه در مرکز اعلان دیگر ارسال را قطع نمی‌کند ولی ماندگاری رکورد در حافظهٔ پر تضمین‌شده نیست.
- مجوز SMS همچنان وجود دارد؛ این بررسی تضمین پذیرش Google Play نیست. Target API و فرم‌های سیاست انتشار باید در زمان ارسال بررسی شوند.
- دادهٔ فعال محلی و بکاپ عادی لزوماً رمزگذاری‌شده نیستند؛ حفاظت فیزیکی گوشی و نگهداری امن بکاپ همچنان ضروری است.
